# DT067 — Tính giá trị biểu thức hậu tố bằng ngăn xếp

Bộ hồ sơ cá nhân của Nguyễn Thành Tân (N24DCDT082), đề tài INT13185 DT067.

## Tệp trong repo

- Báo cáo Word và PDF theo mẫu.
- Mã nguồn đóng gói ZIP.
- Tệp thông tin nộp.
- Ảnh minh chứng A01–A09 trong `Minh_chung/`.

## Chạy ứng dụng

Giải nén ZIP, mở PowerShell tại thư mục có `app.py`, rồi chạy:

```powershell
python -m pip install streamlit pandas
python -m streamlit run app.py
```

## Tình trạng hồ sơ

Báo cáo ghi rõ ZIP mã nguồn hiện có chưa đồng bộ với app.py dùng chụp A01–A09. A10 (clone sạch) và các thông tin SHA/permalink cần bổ sung sau khi đồng bộ mã và chạy lại từ repo. Repo được giữ ở chế độ riêng tư.
